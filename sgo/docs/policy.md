# S-Go target policy (spec 0.18.0)

Generated by `sgo/scripts/policy-report.py` from the sources that enforce the policy; CI fails if it is stale or if those sources disagree. Default deny: anything not listed as admitted is rejected (`SGO_SPEC_ADMISSION.json`).

## Authority

There is no ambient authority. A program's root grants are the `grant` lines of its main module's `sgo.mod` (SGO-AUTH-002), recorded in the binary's build ID (`grants=`); dependencies cannot add grants. Every task has a ceiling: the root's is the grants, a child's is its spawner's minus what `n.SpawnWithout` removes, and nothing widens it (SGO-AUTH-001). An effect operation needs both a handle that permits it and its kind in the calling task's ceiling; otherwise it fails with `MissingCapability` before any effect.

| Kind | sgo.mod | Root accessor | Handle | TCB primitive |
|---|---|---|---|---|
| `clock` | `grant clock` | `root.Clock()` | `*sgo.Clock` | TCB-P13 |
| `wallclock` | `grant wallclock` | `root.WallClock()` | `*sgo.WallClock` | TCB-P13 |
| `random` | `grant random` | `root.Random(seed)` | `*sgo.Random` | none (package sgo, deterministic) |
| `entropy` | `grant entropy` | `root.Entropy()` | `*sgo.Entropy` | TCB-P14 |
| `simstore` | `grant simstore` | `root.SimStore()` | `*sgo.SimStore` | TCB-P15 |

Attenuation: `SimStore.ReadOnly`, `SimStore.Prefix`; handles are shareable authority tokens with no revocation (SGO-AUTH-003, D169).

Capability handle types (opaque, used only behind `*`, never nil, never compared; SGO-TYPE-005): `*sgo.CapacityLimiter`, `*sgo.Channel`, `*sgo.Clock`, `*sgo.Conn`, `*sgo.Context`, `*sgo.Dialer`, `*sgo.Dir`, `*sgo.Entropy`, `*sgo.Event`, `*sgo.File`, `*sgo.Input`, `*sgo.Lease`, `*sgo.Listener`, `*sgo.Listing`, `*sgo.Nursery`, `*sgo.Random`, `*sgo.Ready`, `*sgo.Request`, `*sgo.SendPermit`, `*sgo.SimStore`, `*sgo.T`, `*sgo.Timer`, `*sgo.Token`, `*sgo.WallClock`, `*sgo.Writer` (`Channel` and `SendPermit` only instantiated, SGO-PERMIT-002).

## Trusted computing base

`sgo/TARGET_TCB.json` (SGO-TCB-002): spec 0.18.0, allowlist digest `074a4702db18c59d`, 31 packages, 1089 files (75 changed from upstream), 19 primitives. A file is trusted only at its own import path and file name with its exact SHA-256: neither a package name nor copied content confers trust (W12 R1).
